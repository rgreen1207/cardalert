Currency

Discord free

Right-click a user or role in Discord (with Developer Mode on, under Settings → Advanced) and choose "Copy ID," then paste it into whichever field above fits. Separate multiple IDs with commas to mention several people and/or roles at once. These must be the numeric IDs Discord copies (e.g. 123456789012345678), not usernames — any non-numeric entry is skipped rather than sent as broken text. Every alert starts with all of these mentions.

Best Buy polling free API key

Get a free key at developer.bestbuy.com — sign up, create an app, and copy the API key it gives you.

Target polling optional

Card Alert uses a shared key by default that gets rate-limited from time to time, since everyone using it shares the same limit. Try finding your own automatically, or paste one in manually if that doesn't work: open Target's site in your browser, open dev tools' Network tab, load any product page, find a request to redsky.target.com, and copy its "key" parameter here.

Pokémon Center queue speed

Card Alert checks separately, and much more often, for the Pokémon Center queue specifically, so you're not stuck waiting up to 10 minutes for that alert. Each check is lightweight (it only asks "is the queue live," not the full page), which is what makes checking this often reasonable. Lower is faster; {{ pokemon_center_fast_check_floor }} seconds is the fastest allowed, so this can't be set low enough to become genuinely excessive. There's no true instant push notification available from Pokémon Center, this is the closest thing to it.
