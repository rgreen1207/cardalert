FAQ

My Discord mention isn't actually pinging anyone

Use "Send test alert" and check what it reports, it now says exactly which mention (if any) was included. If it says a mention was included but nobody got pinged in Discord: for role mentions, the role itself needs "Allow anyone to @mention this role" turned on (right-click the role in Server Settings → Roles → the role → General), Card Alert can send the correct mention syntax, but Discord still won't ping an unmentionable role no matter what. For user mentions, double check the ID is the numeric ID from "Copy ID," not a username, a non-numeric value is skipped rather than sent as broken text, and the test result will say so directly.

Why does my Target item show "Blocked by retailer" or "Rate limited, will retry"?

Target's poller uses a fixed API key embedded in the code, the same kind of key you'd see if you opened Target's own site in a browser and watched its network requests. Target occasionally rotates or rate-limits these. "Blocked by retailer" means Target returned a 401/403, most likely the key needs updating, not that anything about your specific product is wrong. "Rate limited, will retry" means a 429, it'll recover on its own on the next poll. Both are shown distinctly from a generic error, and distinctly from "Not found" (which means Target responded fine, just without the usual stock info, e.g. for a delisted or restricted item) — check GitHub Issues if "Blocked by retailer" doesn't clear up after a while, since that one may need an actual code update.

How does the Pokémon Center queue alert work?

Whenever a Pokémon Center product is behind Queue-it's wait room, Card Alert alerts you that the queue is live, using whichever channels that product has configured, the same way a restock does. Unlike restock alerts, this one has no cooldown, it fires again on every poll for as long as the queue stays open, since the point is to always know it's live, not just the first time. Polling for this happens every 10 minutes Mon-Thu 8am-1pm PST (when queues most often happen) and every 30 minutes the rest of the time, so a queue opening outside that window still gets caught.

How do I update Card Alert?

Go to Settings and click "Check for updates," then "Update now" if one's available. It pulls the latest release, reinstalls dependencies, and restarts the app automatically. You can also just re-run the install command from a terminal, which does the same thing.

How do I change or add a notification channel later?

Go to the Settings page (in the nav above) and paste in credentials there any time. No file editing or restart needed. It's the same fields as the first-run setup wizard.

How do I stop getting alerted for overpriced restocks?

On the Products page, set "Max price / MSRP" to the price you're willing to pay. Anything above that, plus whatever percent you allow in "Allow up to (%) over that price," gets silently skipped. No alert, no notification, nothing.

Why didn't I get an alert for something that was in stock?

Check three things: (1) the item is marked active, not paused, on the Products page; (2) the price was at or under your max price cap; (3) your chosen alert channel has valid credentials in .env. Dashboard alerts always show up regardless of channel, so check there first.

Why does my Amazon item show "THIRD_PARTY_SELLER_ONLY"?

That means the listing is in stock, but only from a third-party marketplace seller, not Amazon itself. Card Alert only alerts on listings that say "Ships from and sold by Amazon.com," since third-party listings on hot TCG products are usually marked up well above MSRP. Amazon also changes its page layout more often and fights scraping harder than any other retailer here, so this poller is the most likely one to occasionally need a fix. Check GitHub Issues if it seems stuck.

A retailer's poller stopped working. Is that a bug?

Usually means the retailer changed their page structure. Check GitHub Issues for a fix, or file one. This happens periodically and isn't something Card Alert can fully prevent.

Can this add things to my cart or check out for me?

No, by design, in every tier. It only reads public stock/price info and alerts you. See LICENSE.md for why.

Notification setup

Set which channel each item uses from the "Alert via" dropdown when adding it. Fill in the matching credentials in your .env file first. Instructions below.

Discord free

  1. In your Discord server: Server Settings → Integrations → Webhooks → New Webhook.
  2. Pick the channel it should post to, copy the Webhook URL.
  3. Set DISCORD_WEBHOOK_URL in .env.

ntfy free, no signup

  1. Install the ntfy app (iOS/Android) or use a browser at ntfy.sh.
  2. Subscribe to a topic name you make up. Treat it like a password, e.g. cardalert-yourname-x92q7.
  3. Set NTFY_TOPIC in .env to that same name.

Pushover ~$5 one-time, paid to Pushover

  1. Create a free account at pushover.net and install the app.
  2. Copy your User Key from your account page.
  3. Create an "Application" (any name) to get an API Token.
  4. Set PUSHOVER_USER_KEY and PUSHOVER_APP_TOKEN in .env.

The $5 charge happens inside the Pushover app itself after a trial period. Card Alert never touches that payment.

SMS via Twilio your own account, fractions of a cent/text

  1. Create a free Twilio account at twilio.com (includes trial credit).
  2. Copy your Account SID and Auth Token from the console.
  3. Buy a Twilio phone number (a few dollars/month after trial).
  4. Set TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_FROM_NUMBER, and TWILIO_TO_NUMBER (your real phone, e.g. +12065551234) in .env.

Every text after that is billed directly to your Twilio account. Card Alert never sees or handles that billing.

MSRP cap

"Ignore if over MSRP by (%)" hides restocks priced too far above sticker price from triggering an alert. Set it to 0 to only alert at exact MSRP or below, or e.g. 15 to allow up to 15% over before it's ignored.
