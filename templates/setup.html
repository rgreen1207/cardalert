WELCOME TO CARD ALERT

Card Alert works right away with no setup — you'll see restock alerts right here on the dashboard. The steps below are optional: they let alerts reach you on Discord, your phone, or by text instead of only showing up when you have the dashboard open. Skip anything you don't want — you can always come back and add it later from Settings.

Discord free

Server Settings → Integrations → Webhooks → New Webhook → copy the URL.

ntfy push notifications free, no signup

Install the ntfy app, subscribe to a topic name you make up (treat it like a password), enter that same name here.

Pushover ~$5 one-time, paid to Pushover

Create a free account at pushover.net, install the app, copy your User Key and create an Application for an API Token.

SMS via Twilio your own account, fractions of a cent/text

Free Twilio account, copy your Account SID + Auth Token, buy a phone number.

Best Buy polling free API key

Only needed if you plan to watch Best Buy items — free key from developer.bestbuy.com.
